== 文件存储模块

`test-infra-storage-file` 提供 MinIO / SFTP / FTP 测试基础设施。

=== Maven 坐标

[source,groovy,subs="attributes+"]
----
testImplementation 'io.github.wkaylves:test-infra-storage-file:{infraVersion}'
----

=== SharedMinIOContainer

MinIO 单例容器，兼容 S3 API。

[source,java]
----
class MinioIntegrationTest {
    @Container
    static GenericContainer<?> minio = SharedMinIOContainer.getInstance();

    @Test
    void shouldConnect() {
        String endpoint = SharedMinIOContainer.getEndpoint();
        // 使用 endpoint 连接 MinIO
    }
}
----
