== JUnit5 Module

`test-infra-junit5` provides generic JUnit5-level extensions and conventions.

=== Maven Coordinates

[source,groovy,subs="attributes+"]
----
testImplementation 'io.github.wkaylves:test-infra-junit5:{infraVersion}'
----

=== BaseJUnit5Test

JUnit5 test platform with automatic AssertJ Soft Assertions injection. Extend this class to use the `softly` field for soft assertions in test methods.

[source,java]
----
@ExtendWith(MockitoExtension.class)
class OrderServiceTest extends BaseJUnit5Test {
    @Mock
    private OrderRepository orderRepository;

    @InjectMocks
    private OrderService orderService;

    @Test
    void shouldVerifyMultipleFields() {
        Order order = new Order();
        order.setOrderNo("ORD-001");
        order.setCustomerName("Alice");

        when(orderRepository.save(any())).thenReturn(order);

        Order result = orderService.createOrder(order);

        softly.assertThat(result.getOrderNo()).isEqualTo("ORD-001");
        softly.assertThat(result.getCustomerName()).isEqualTo("Alice");
    }
}
----

[TIP]
====
Pure Mockito scenarios can still use native `@ExtendWith(MockitoExtension.class)` directly, without extending a base class.
====
