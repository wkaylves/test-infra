== RPC Mock Module

`test-infra-rpc-mock` provides Dubbo / gRPC mock utilities.

=== Maven Coordinates

[source,groovy,subs="attributes+"]
----
testImplementation 'io.github.wkaylves:test-infra-rpc-mock:{infraVersion}'
----

=== DubboTestBase

Dubbo mock base class providing Dubbo service test support.

[source,java]
----
class OrderServiceDubboTest extends DubboTestBase {
    @Test
    void shouldCallDubboService() {
        // Dubbo mock test
    }
}
----

=== GrpcTestBase

gRPC mock base class providing gRPC service test support.

[source,java]
----
class OrderServiceGrpcTest extends GrpcTestBase {
    @Test
    void shouldCallGrpcService() {
        // gRPC mock test
    }
}
----
